## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- **HTML** e **CSS**: Para a estrutura e estilo da página.
- **JavaScript**: Para interatividade e funcionalidades dinâmicas.
- **Git** e **GitHub**: Para controle de versão e colaboração.
- **Figma**: Para design e prototipagem do layout.

## 💻 Projeto

O **DevLinks** é um agregador de links que funciona como um cartão de visitas online. Ele permite que você compartilhe seus links mais importantes de forma organizada e acessível.

## 🔖 Layout

Você pode visualizar o layout do projeto através [DESSE LINK](https://www.figma.com/design/soUcOTXXUd087c3xw5STH4/DevLinks-•-Projeto-Discover-(Community)?t=LcVpmS3jqKXD1Hcv-0). É necessário ter uma conta no [Figma](https://figma.com) para acessá-lo.
